# Airflow Gaming Pipeline

Hands-on Apache Airflow project focused on
orchestrating a gaming telemetry data pipeline.

## Objectives

- Learn DAGs and task dependencies
- Schedule automated data pipelines
- Implement retries and failure handling
- Orchestrate Bronze, Silver, and Gold data layers
- Apply Git and CI/CD best practices

## Tech Stack

- Python
- Apache Airflow
- Docker
- GitHub Actions
